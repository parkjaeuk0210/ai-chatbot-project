# PERA 코드베이스 심층 진단 및 리팩터링 기록

## 목표

기존 기능을 무작정 확장하지 않고, 유지보수성과 신뢰를 높이면서 사용자가 질문·첨부·이미지 생성에 곧바로 집중할 수 있는 단일 화면 경험을 만든다.

## 발견한 구조적 문제

### 1. 실행 코드와 모듈 코드의 분리 실패

실제 `index.html`에는 대량의 CSS와 JavaScript가 다시 인라인으로 합쳐져 있었고, `css/`와 `js/`에는 별도 구현이 남아 있었습니다. 같은 기능이 둘 이상의 장소에 존재해 버그 수정과 보안 검토의 기준점이 불명확했습니다.

**결정:** HTML은 의미 구조만 유지하고, 스타일은 `css/styles.css`, 동작은 `js/main.js`로 단일화했습니다. 정적 검사에서 인라인 `<style>`과 인라인 `<script>`의 재도입을 차단합니다.

### 2. API 계약의 분산

프런트가 레거시 엔드포인트를 호출하는 동안 서버에는 여러 채팅 핸들러가 공존했고, 역할 이름·필수 `sessionId`·이미지 응답 형식이 서로 달랐습니다.

**결정:** 브라우저는 `/api/chat` 하나만 호출합니다. 서버는 텍스트와 이미지 요청을 명시적으로 검증하고, 공급자 응답을 하나의 `candidates[].content.parts[]` 계약으로 정규화합니다.

### 3. 안전하지 않은 동적 렌더링

사용자 또는 모델 문자열을 HTML로 삽입하는 경로는 XSS 검토 범위를 넓히고 CSP를 약화시킵니다.

**결정:** 메시지와 오류는 `createElement`, `textContent`, `replaceChildren`만 사용합니다. 프런트 계약 테스트에서 `.innerHTML` 사용을 금지합니다.

### 4. 모바일 복잡성의 과잉

스와이프 탭 전환, 헤더 자동 숨김, viewport 메타 변경, 가상 키보드 추정 로직이 기본 흐름보다 많은 상태와 예외를 만들었습니다.

**결정:** 브라우저의 `dvh`, 자연스러운 스크롤, 고정된 composer에 맡기고 사용자에게 보이는 탭과 키보드 동작만 유지했습니다.

### 5. 개인정보 대비 가치가 낮은 언어 감지

언어 선택을 위해 외부 IP 위치 API를 호출하고, 과거 오타가 포함된 저장 키가 누적되어 있었습니다.

**결정:** URL 매개변수 → 로컬 설정 → 브라우저 언어 순서로만 결정합니다. 네트워크 기반 위치 감지는 제거하고 레거시 키는 한 번 마이그레이션합니다.

### 6. 배포 산출물 계약 부재

Vercel 프로젝트는 `public/`을 기대했지만 기존 빌드는 CSS만 생성했습니다. 결과적으로 빌드는 완료된 것처럼 보인 뒤 산출물 부재로 실패했습니다.

**결정:** `scripts/build.mjs`가 `public/`을 새로 만들고 승인된 정적 파일만 복사합니다. `vercel.json`의 `outputDirectory`와 자동 검사가 이 계약을 고정합니다.

## UI/UX 결정

- 고정 사이드바 없이 **채팅 / 이미지** 두 모드만 제공합니다.
- 헤더는 브랜드, 준비 상태, 새 대화, 테마, 설정만 남깁니다.
- 비어 있는 채팅 화면에 세 개의 시작 제안만 제공해 선택 부담을 줄입니다.
- composer는 첨부·입력·전송을 하나의 시각 단위로 묶습니다.
- 결과 메시지 폭, 행간, 대비, 여백을 읽기 중심으로 조정합니다.
- 다크 모드는 동일한 계층과 대비를 유지하며 장식 효과를 추가하지 않습니다.
- 모바일에서는 기능을 숨기기보다 헤더 라벨과 여백을 압축합니다.

## 엔터프라이즈 품질 게이트

- CSP에서 `unsafe-inline`, `unsafe-eval`을 사용하지 않음
- 브라우저 코드에 비밀키 또는 `process.env` 없음
- API 요청 크기, 메시지 크기, 역할, 파일 MIME, 세션 ID 검증
- 요청 제한 및 upstream timeout
- API 응답 `Cache-Control: no-store`
- 전 언어 번역 키 일치 테스트
- 키보드 탭 패턴, dialog, live region, reduced-motion 지원
- `check → test → build` 실패 시 배포 중단

## 의도적으로 추가하지 않은 것

- 3패널 Studio/Workbench
- 상시 대화 목록 사이드바
- 복잡한 명령 팔레트와 다중 작업 모드
- 클라이언트 측 분석 SDK와 외부 언어 감지
- 브라우저에 저장되는 API 키
- 서버 없는 클라이언트 직접 모델 호출

이 비기능 범위는 제품이 실제로 요구할 때 독립된 데이터 모델과 사용자 검증을 거쳐 추가해야 합니다.
